# Portfolio Sim Frontend

## Pages

- `/dashboard` - Portfolio overview, P&L, allocation
- `/portfolio` - Holdings, transactions, performance charts
- `/strategy` - Backtesting, strategy builder
- `/news-feed` - News articles, video summaries
- `/observability` - Logs, metrics, system health

## Components

- `Navbar` - Top navigation with route links
- `PageLayout` - Shared layout wrapper
- `ui/` - Reusable UI components (Button, Card, Input, Table, Badge)

## Tech Stack

- Next.js 16 with App Router
- TypeScript
- CSS Modules / Tailwind (globals.css)

## Getting Started

```bash
cd frontend
npm install
npm run dev
```
